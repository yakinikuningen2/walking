# walking

場所を検索し、行った場所を地図に記録する散歩アプリです。

## 使い方

1. VS Code の Live Server でルートの `index.html` を開きます。
2. 地図の左端にある「場所を登録」の取っ手を右に引っ張るかクリックしてパネルを開き、場所の名前や住所を入力すると候補が表示されます。候補から場所を選びます。虫眼鏡や Enter キーでも検索できます。
3. 場所の名前・訪問日・メモを入力し、「保存」を押します。
4. 保存した場所を一覧から選ぶと地図に表示できます。編集・削除・直前の削除の取り消しもできます。

検索で見つからない場所は、地図をクリックして直接登録できます。
保存した場所にメモがある場合は、地図のポイントの上に常時表示します。メモの編集・削除は地図上の表示にも反映されます。
パネルは取っ手を左に引っ張る、取っ手をクリックする、または Escape キーで閉じられます。地図は常に画面いっぱいに表示し、パネルを左から重ねて引き出します。入力途中の内容は開き直しても残ります。マウス・タッチ操作に対応しています。
通常のホイール操作は地図の移動、Ctrl＋ホイールやタッチパッドのピンチは拡大・縮小です。

## 現在地

地図右下の「現在地を取得」を押し、ブラウザの位置情報へのアクセスを許可すると、現在地を青い丸で表示して地図の中心を移動します。薄い青の円は位置情報の誤差の範囲です。もう一度押すと最新の位置を取得します。

- HTTPS、または Live Server の `http://localhost:ポート番号`・`http://127.0.0.1:ポート番号` で開いてください。HTTP の LAN アドレスでは位置情報を取得できません。
- ブラウザと端末の位置情報の許可が必要です。許可拒否・取得失敗・タイムアウトは画面に表示します。
- ボタンを押した時だけ取得します。現在地を訪問記録として保存したり、自動で追跡したりしません。

## 目的地

地図右下の「目的地を検索」を押し、目的地の名前・住所を入力すると候補が表示されます。候補を押すと、その場所を直接目的地に指定します。目的地の指定時は地図の縮尺を変えず、表示の中心だけ移動します。

「場所を検索」の候補や地図上の場所を選び、「目的地に指定」を押すこともできます。登録地点は一覧や地図上の詳細表示からも指定できます。場所の名前や訪問記録を保存する前でも指定できます。目的地は赤い丸と「地図マーカーのアイコン素材4.png」のアイコンを合わせて表示します。

目的地を指定すると検索パネルが閉じ、地図右下に目的地の情報と「目的地を解除」ボタンが表示されます。別の場所を指定すると目的地が切り替わります。入力中の訪問記録は保持します。目的地は現在のページ内で保持し、再読み込みすると解除されます。

## 徒歩ルート案内

目的地を指定し「徒歩ルートを表示」を押すと、最新の現在地を取得して、歩ける道路に沿ったルートを青い線で表示します。距離と徒歩の所要時間を表示し、「道順」を開くと出発・右左折・分岐・到着の案内を日本語で確認できます。道路名は地図データの表記を使用します。

目的地の切り替えや、案内中の「現在地を取得」でルートを更新します。「ルートを更新」でも最新の現在地から計算し直せます。「案内を終了」で線と道順を消します。目的地を解除すると案内も終了します。ルート表示による自動拡大は行いません。

- [FOSSGIS の徒歩専用 OSRM サービス](https://routing.openstreetmap.de/about.html)を利用します。車用ルートは使用しません。ルートを取得する際は現在地と目的地の座標をこのサービスへ送信します。
- リクエスト間隔は最低1秒です。取得できない場合は理由を表示します。徒歩ルートを取得できない地点を直線で結んだ案内は表示しません。
- 所要時間は推定です。移動中の位置情報は自動追跡せず、更新ボタンで再取得します。音声案内はありません。

## 保存と検索

- 記録はブラウザの localStorage に保存されます。端末間の同期はありません。
- 同じブラウザ・同じオリジン（プロトコル、ホスト、ポート）で再度開くと、記録を復元します。
- ブラウザのサイトデータを消すと記録も消えます。
- 地図と検索にはインターネット接続が必要です。検索できない場合も地図から手動で登録できます。
- 検索は [Photon](https://github.com/komoot/photon) の公開デモAPIを利用します。入力が約350ミリ秒途切れると自動検索し、日本語の変換前・変換中も候補を検索します。変換確定の Enter キーは検索の送信として扱いません。結果をセッション内でキャッシュし、連続リクエストは1秒以上間隔を空けます。入力を変えると前の検索を中止し、空欄にすると候補とメッセージを消します。
- 検索候補は最大15件です。国名は国コードから日本語に変換し、住所は現地語で取得して国内の地名を日本語で表示します。現在の公開APIは日本語指定に対応していないため、日本国外の都市名・道路名などは現地語表記が残る場合があります。
- Photon のデモAPIは適度なリクエスト数での利用向けで、稼働保証はありません。多数のユーザーに公開する場合は専用の検索サーバーに変更してください。接続先は `static/js/app.js` の `SEARCH_ENDPOINT` にあります。
- 検索語は検索サービスに送信されます。訪問日・メモ・記録一覧は送信しません。
