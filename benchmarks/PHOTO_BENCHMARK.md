## 改善の根拠と追加試験

- 日本大学文理学部：検索名から正式記事へのリダイレクトを確認し、住所欄の「東京都・世田谷区・桜上水」と検索地点の所在地を照合。座標のない記事でも高信頼度となり、[入口の写真](https://commons.wikimedia.org/wiki/File:Nihon_univ_college_of_humanities_and_sciences_2009.JPG)を取得しました。撮影者Kamemaru2000、CC BY-SA 3.0、撮影年2009年です。現在の景観と同じことを保証する写真ではありません。
- ご指定の[施設専用カテゴリ](https://commons.wikimedia.org/wiki/Category:College_of_Humanities_and_Sciences,_Nihon_University)を関連タグに入れた試験も成功。「日大文理」と正式名称・英語名を渡した試験も成功しました。特例は本番の検索処理に追加していません。
- 新たに取得：井笠鉄道記念館、瑞鳳殿資料館、苫前町郷土資料館、渋谷ワイナリー東京、日本大学文理学部。
- 同名の別施設：GeoNamesの中央公園2地点・城山公園3地点で検索。城山公園は綾瀬市と埼玉県の地点で異なる写真を取得し、照合できない地点は採用しませんでした。
- 寺院：城泉寺・願成寺で実APIを確認。両方で写真を確認できず、存在未確認として扱います。別施設の写真で補完しません。
- 小規模公園：Photon/OSMの[新宿区百人町の公園](https://www.openstreetmap.org/way/467845844)でも実APIを確認。外接矩形からの概算は約92平方メートル（公式の公園面積ではありません）、データ上の名称は単に「公園」です。改善前後とも写真は採用されず、存在未確認として扱います。桜上水の小規模公園も調べましたが、Overpassの2提供元がタイムアウトしたため、こちらは検証成功に数えていません。
- 地点に合わない明示ID：大阪の座標へ明治神宮のIDを渡す負例では、改善前後とも写真を採用しませんでした。これは実在地点の移設を示すデータではなく、誤関連付けを想定したテストです。
- PC 1440×900、スマホ390×844・320×568のChrome：写真・16:9・拡大・閉じる・登録・周遊・ポップアップ再表示・写真なし・API失敗・徒歩ルートの回帰を確認。実機Safari・Render本番は未実施です。
- 最終コードを記録済み113地点のAPI応答で再生し、取得写真のURLに差がないことも確認しました。

## 照合規則

施設の正式名称・別名・略称・英語名、全半角・空白・括弧を正規化して候補を取得します。意味のある括弧内の学部名等は消しません。WikipediaのリダイレクトとWikidataの別名も同一名の根拠にします。

| 根拠 | 点数・扱い |
| --- | --- |
| 名称・正式な別名の一致 | 60点、中信頼度。これだけで採用しない |
| 1.2km以内の施設座標 | +30点 |
| 市区町村＋町名等の具体的な住所一致 | +30点 |
| 明示された関連ID・記事・施設専用カテゴリ | 90点 |
| 施設の種類の一致 | 補助+5点。種類だけで採用しない |
| 既知の座標が2km以上離れる・既知の所在地が矛盾する等 | 他の点数より優先して除外 |

90点以上を高信頼度として採用、60点以上90点未満は住所フィールド等を追加照合、それ未満は不採用とします。これは確率や統計的な「90%正しい」を表す数値ではありません。一般のCommons名前検索は撮影座標500m以内を確認し、「周辺の写真」と明記します。ライセンス確認・著作者・出典表示はすべての経路で維持します。

同時2件、外部呼び出しの間隔250ms、1地点最大8回・18秒目安、応答最大1MBは維持。1回の検索内で同一問い合わせを再利用し、地点単位の既存メモリキャッシュも維持します。画像は非同期・遅延取得で、有料API・新しいライブラリはありません。

## 再現方法・出典

[地点別CSV](photo-results.csv) と [追加11ケースのCSV](photo-controls.csv) は画像の実体・記事本文・座標を含まない評価表です。提供元の列と各画像の個別出典URLを保持します。追加ケースは主比較の113地点と別枠であり、重複する日本大学文理学部等を分母に加えていません。`before_photo_valid` は地図等を除いた写真判定です。`before` の `found` は旧処理が画像を返したという意味なので混同しないでください。`existence=unconfirmed` は写真なしの断定ではありません。

改善前の自作処理を [photo_before.py](photo_before.py) に固定しました（SHA-256：`ef8323edaca4edbe77d6f2245b5baf4b13351484488bf8c076449929d461494f`）。アプリからは読み込みません。外部通信のある検証は明示実行のみで、同梱データの版と同じ入力を使います。

```powershell
$photoAudit = Join-Path $env:TEMP 'walking-photo-benchmark'
.\.venv\Scripts\python.exe -B benchmark_place_photos.py --baseline benchmarks\photo_before.py --work $photoAudit --stage before
.\.venv\Scripts\python.exe -B benchmark_place_photos.py --baseline benchmarks\photo_before.py --work $photoAudit --stage after-final
.\.venv\Scripts\python.exe -B audit_place_photos.py --baseline benchmarks\photo_before.py --work $photoAudit --output benchmarks --after-stage after-final
```

生のAPI応答（Wikipedia本文を含むことがある）はリポジトリ外の一時フォルダーにのみ保存します。測定をやり直す場合は別の一時フォルダーを指定してください。同じフォルダーなら以前に完了したケースを再利用します。APIの更新・混雑で同じ結果や時間になる保証はありません。途中測定では2件の通信エラーを観測しましたが、最終版の113件では0件でした。

地点の出典：Wikidata（CC0）、GeoNames（CC BY 4.0）、国土交通省の鉄道2025年度版（CC BY 4.0）、日本大学文理学部の検索地点はPhoton経由のOpenStreetMap（ODbL）。取得版・原本URL・加工条件は [データ台帳](../static/data-licenses.json) と [外部利用条件](../THIRD_PARTY_NOTICES.md) を参照。写真はCommons各ファイルのライセンスに従い、評価に写真バイナリを同梱しません。

## 残る課題

未確認地点を写真なしと決めつけないこと、詳細な住所がない同名施設、複数の敷地を持つ施設、記事やカテゴリの誤関連付けは引き続き課題です。地図等の除外はメタデータによる規則で、すべての画像を画像認識で判定するものではありません。正確さを保ったまま取得率を大幅に上げるには、公開データ側の写真・別名・所在地・施設専用カテゴリの整備も必要です。
