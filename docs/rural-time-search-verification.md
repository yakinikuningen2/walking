# 下限指定後の田舎寄り検索の確認

確認日：2026-11-22。

## 指定された条件

- 出発地：秋津駅付近の公開座標（35.7787, 139.4966）
- 片道時間：00:00～06:00
- 種類：神社、雰囲気：田舎寄り、方角：西
- 歩く速さ：時速4kmで再現。実際の利用者の保存速度は読み取っていない。

既存のWikidata同梱神社データには、時間・方向に一致する候補が70件存在した。周辺API失敗を再現すると、以前は更新通知も最終表示も0件になった。下限00:30では69件、05:00では19件の実在候補があったが、同じ周辺確認の失敗で表示を失っていた。田舎寄りを確認できた候補数とは区別する。

## 修正

同梱データの候補を先に表示し、周辺確認前・失敗時には「田舎寄りは未確認」と明記する。未確認の参考候補は最大10件とし、時間・カテゴリ・方角・並び順は維持する。周辺APIによって市街地と判定された地点は除外し、正常に確認できた候補が十分にそろったら参考候補を取り下げる。失敗を「該当地点なし」や「確認済み田舎」とは扱わない。既存の公開API以外の新しいサービスは追加していない。

## 結果

PC 1440×900、スマートフォン390×844・320×568のChromeで、実際の同梱神社JSONと、周辺APIの失敗・正常復旧を固定応答で検証。未確認候補10件が表示され、加治神社、阿蘇神社などを確認した。表示候補すべての予想時間が6時間以内、神社、西方向であり、予想時間の長い順になっていることを確認。未確認状態の履歴保存、復旧後の確認済み候補への置換も成功。コンソール例外0件。

PCからOverpassへ実通信した場合も約7.1秒で周辺確認の失敗が終了し、10件の参考候補が残った。実通信でこれらを田舎と確認できたわけではない。初期表示約74～91msは同梱JSONをローカルテストサーバーから読んだ固定応答検証の値で、Render上の速度の保証ではない。実機iPhone・現地の状況は未検証。本番へのpush・デプロイは実施していない。

`node --test --test-timeout=20000 test_*.cjs` に、指定条件の回帰検証（下限00:00・00:30・05:00）、未確認を一致と扱わない確認、市街地の除外、失敗キャッシュの抑止、復旧後の置換を含む。神社データの出典・CC0条件はREADMEおよびアプリ内「出典・ライセンス」を参照。
